# RiskLens: Banking Fraud Analytics Using Machine Learning and Power BI

Senior Seminar II (CSCI 412) project by Prashant Tiwari.

RiskLens compares Logistic Regression, Random Forest, and XGBoost for detecting
fraudulent transactions in the BankSim synthetic dataset. A Power BI dashboard
is planned for the second half of the semester.

> BankSim is synthetic. Results do not show how the models would perform in a real bank.

## Data and evaluation design
- Dataset: BankSim synthetic payment transactions (file `bs140513_032310.csv`),
  594,643 transactions of which 7,200 are fraudulent (1.21%). The raw file is not
  stored in this repository. Download it from the source you used and save it as
  `data_raw/bs140513_032310.csv`.
- Chronological split by simulation step: train 0-107, validation 108-143, test 144-179.
- Predictors: transaction amount and category.
- Preprocessing and models are fitted on training data only. Model settings and
  decision thresholds are chosen on validation data. The test partition has not been used.

## Validation results (each model at its selected threshold, 0.98)
| Model | Precision | Recall | F1 | Average precision |
|---|---|---|---|---|
| Logistic Regression | 0.818 | 0.633 | 0.714 | 0.767 |
| Random Forest | 0.892 | 0.635 | 0.742 | 0.803 |
| XGBoost | 0.854 | 0.656 | 0.742 | 0.796 |

Differences between the models are small and were not tested for statistical significance.

## How to reproduce
1. Use Python 3.11 and run `pip install -r requirements.txt`.
2. Put the BankSim CSV in `data_raw/`.
3. Run the notebooks in `notebooks/` in order:
   1. `RiskLens_01_Data_Preparation.ipynb`
   2. `RiskLens_02_Modeling_Optimized.ipynb`
   3. `RiskLens_03_Model_Comparison.ipynb`

The folders `data_processed/`, `database/`, and `models/` are generated by the
notebooks and are not stored in this repository.

## Repository layout
- `notebooks/`: the three notebooks
- `outputs/`: charts and summary tables (SQL results, metrics, model comparison)
- Power BI dashboard: planned, not yet built

## Limitations
BankSim is simulated, only two predictors are used here, and every simulation step in
the training and validation data contains exactly 40 fraud cases, so time trends reflect
the simulator, not real fraud behavior.
